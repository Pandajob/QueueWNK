# สคริปต์ Google Apps Script

ตัวช่วยส่งข้อความเข้ากลุ่ม LINE ผ่าน **MOPH Notify** จากงานที่อยู่นอก QueueWNK
เช่น Google Form หรือหน้าเว็บที่ทำด้วย Apps Script

ไม่ได้เป็นส่วนหนึ่งของตัวระบบ QueueWNK และไม่ต้องติดตั้งเพื่อให้ QueueWNK ทำงาน
เก็บรวมไว้ที่นี่เพราะใช้ MOPH Notify ตัวเดียวกันและกลุ่มเดียวกันได้

| ไฟล์ | ทำอะไร |
| --- | --- |
| [`FlexPurple.gs`](FlexPurple.gs) | ตัวสร้างการ์ด Flex โทนม่วง และตัวส่งเข้า MOPH Notify — ไม่ต้องแก้ |
| [`FormNotify.gs`](FormNotify.gs) | รับคำตอบจาก Google Form แล้วส่งการ์ดเข้ากลุ่ม ใช้คู่กับ `FlexPurple.gs` |
| [`HisRegister.gs`](HisRegister.gs) | ฟอร์มสมัครใช้บริการ HIS — บันทึกลง Sheet แล้วแจ้งเข้ากลุ่ม (ใช้เดี่ยวได้) |

## ตั้งค่ากุญแจ

ทุกไฟล์อ่านกุญแจจาก **Project Settings → Script Properties** ไม่ฝังในโค้ด

| ชื่อ | ค่า |
| --- | --- |
| `MOPH_BASE_URL` | `https://<host ของ MOPH Notify>` |
| `MOPH_CLIENT_KEY` | client-key ของกลุ่ม |
| `MOPH_SECRET_KEY` | secret-key ของกลุ่ม |

`HisRegister.gs` ใช้เพิ่มอีกสองตัวถ้าเปิดใช้ Telegram — `TELEGRAM_TOKEN` และ `TELEGRAM_CHAT_ID`

> **อย่าพิมพ์กุญแจลงในไฟล์** ไฟล์พวกนี้ถูกก๊อปไปวาง ส่งต่อ และแปะในแชทได้ง่ายมาก
> กุญแจที่ฝังในโค้ดจะหลุดสักวันหนึ่งเสมอ ถ้าหลุดไปแล้วให้ออกกุญแจใหม่ทันที
> — MOPH Notify ที่ CMS เมนู "กลุ่มบอท" · Telegram ที่ @BotFather → `/revoke`

## ขอกลุ่มและกุญแจ MOPH Notify

1. สร้างกลุ่ม LINE ตั้งชื่อ**ลงท้ายด้วย `HC` ตามด้วย hoscode 5 หลัก**
2. เชิญบัญชี **"LINE หมอพร้อม"** เข้ากลุ่ม
3. ให้ admin หน่วยบริการอนุมัติใน CMS MOPH Notify เมนู **"กลุ่มบอท"**
4. กลุ่มขึ้นสถานะ "อนุมัติ" แล้วจะเห็น client-key / secret-key

**กลุ่มปลายทางผูกมากับคู่กุญแจ** ไม่มีช่อง "ส่งถึงใคร" เหมือน LINE Messaging API
จะเปลี่ยนกลุ่มต้องเปลี่ยนกุญแจ ใช้หลายกลุ่มก็ขอหลายชุด

## ก่อนส่งจริง

ทุกไฟล์มีฟังก์ชันตรวจกุญแจที่**ไม่มีข้อความโผล่ในกลุ่ม** — ยิงคำขอที่ไม่มี `messages`
ปลายทางตรวจกุญแจก่อนตรวจ body เสมอ

- ตอบ `require messages` → กุญแจถูก (ผ่านด่านมาแล้วถึงมาบ่นเรื่อง body)
- ตอบ `Unauthorized` → กุญแจผิด

รันอันนั้นก่อนเสมอ ส่วนฟังก์ชันที่ชื่อขึ้นต้นด้วย `test` จะส่งเข้ากลุ่มจริง

## ข้อควรรู้

**ส่งเป็นข้อความตัวอักษรจะถึงเร็วกว่ามาก** ปลายทางมีคิวแยกกัน คำขอที่มีการ์ด Flex
ปนอยู่เข้ากลุ่มช้ากว่าราว **19 นาที** และช้าทั้งคำขอ ไม่ใช่แค่ตัวการ์ด
อยากให้ข้อความด่วนถึงทันทีต้องแยกคำขอ อย่ารวมใน `messages` ชุดเดียวกับการ์ด

**เลขบัตรประชาชนถูกตัดทิ้งก่อนส่งเสมอ** ทุกไฟล์เรียก `scrub_()` ที่ชั้นล่างสุด
ปลายทางเป็นกลุ่มแชทที่มีคนอ่านหลายคน และข้อความ error ที่เผลอต่อท้ายมา
ก็อาจมีเลขบัตรติดมาได้ อย่าถอดออก
